# BoneSystemForNPC

版本：1.7.5  
作者：Laz

## 简述

让已正确加载兼容外观的人类与龙人 NPC 使用对应的 BoneSystem 骨架和脸部、表情设置，
并可同步差分管理器保存的衣服、头发、饰品显隐。

需要配套的 NPC 外观替换包将指定 NPC 替换为玩家的某件装备，先装好完整模型与所需部件。

## 前置要求

- **REFramework**，需要采用支持非 Pak 文件加载的较新版本。截止本说明完成时，最新版本 REF Nightly 01424 有其他 Pak 加载问题，与一些 Mod 存在冲突，建议不要使用 REF Nightly 01424。
- **BoneSystem**，感谢南风焓大佬的前置。链接：https://www.caimogu.cc/post/1937594.html
- 你想用来替换 NPC 外观的原外观 Mod。
- (可选) **差分管理器 4.3.0** 及以上，新版本已经兼容了本 Mod，感谢 MK 佬的支持。可以将差分管理器的差分设置同步给NPC，**强烈建议安装该 Mod 用于设置差分**。链接：https://www.caimogu.cc/post/2301016.html
- (可选) **LifetimeGuard 0.6.0** 及以上，用于解决游戏的卡加载、模型加载不出来问题。本 Mod 会极大的加大造成卡加载的可能性，**强烈建议安装该 Mod 解决卡加载问题**。链接：https://www.caimogu.cc/post/2499136.html

## 安装与使用

1. 下载本压缩包。
2. 通过 Mod 管理器或手动解压安装前置和本包。
3. NPC 已加载的外观具有匹配配置时会自动适配，通常不需要额外设置。
4. 按需要开启脸部、表情映射和差分同步；语言可切换为中文或 English。

**目前支持人类与龙人 NPC**，特定 NPC 的替换包需要隐藏一些附件（比如阿尔玛的眼镜附件需要隐藏）。
龙人替换包会自动使用龙人骨骼修正（测试），无需对龙人 NPC 进行额外处理。
制作对应的 NPC 替换包可以参考 NPC 替换示例，示例使用的基础模型是 DeepSeekGirl by MK，与其适配的 NPC 替换示例可以在原 DeepSeekGirl 链接下载，再次感谢 MK 佬的支持。链接：https://www.caimogu.cc/post/2459428.html

**如果想制作其他外观 Mod 的 NPC 替换包，建议把替换示例的说明喂给 AI，尝试成功后建立 skill，之后就可以交给 AI 处理。**

自动接管不会补齐未加载的装备部件。若你安装的外观 Mod 替换的原套装是某些 NPC 的混搭装备时，可能显示不完整或装备杂乱，可将该名 NPC 的外观替换为整套装备来解决。

## 注意事项

- 在部分场景（初见巨戟龙播片、任务结算画面）会出现 NPC 漂移、动作不正确的问题，这个问题暂时无法解决，可能需要修改这些场景的动作。
- 龙人的额外骨架修正属于测试功能，实际效果可能不稳定。
- 大量 NPC 同时使用复杂外观时，可能明显增加性能消耗，造成掉帧、卡顿或加载变慢。**配置较低或显存紧张时请慎用**。
- 没有修改音效，因此男性 NPC 依然是原声，介意的话慎用。
